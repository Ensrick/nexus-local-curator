# Contributing

Run `npm ci` followed by `npm run check` before proposing code changes. Bugs should include the extension version, reproduction steps, and the privacy-safe diagnostics export when relevant. Never post a Nexus API key.

Community blocklist changes belong in `community/blocklist.csv`. Keep one stable author per row, prefer the public Nexus user ID when known, and describe the list only as a discovery preference. Hidden authors, Keep/Skip decisions, private notes, and accusations do not belong in the public list.

Every blocklist change must remain reviewable as an ordinary pull request or issue and must be removable when an identity is wrong or stale.
