# Community blocklist

`blocklist.csv` is the public, reviewable Excluded-author list. It contains only public Nexus usernames and user IDs. It must never contain API keys, email addresses, private notes, Hidden-author entries, or mod decisions.

The list is a discovery preference, not an allegation of misconduct. Contributions should add one author per CSV row, avoid subjective accusations, and remain reversible through normal version control review.

To use it, download the CSV and import it from **Manage → Import CSV or JSON**. Import merges entries into the local list; it does not replace private Keep, Skip, or Hidden data.
